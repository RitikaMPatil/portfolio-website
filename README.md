# 🌐 Personal Portfolio Website

A modern and fully responsive personal portfolio website built to showcase my skills, projects, certifications, resume, and contact information.

## ✨ Features

- Fully Responsive Design
- Modern UI/UX
- Dark & Light Mode
- Smooth Animations
- Interactive Project Showcase
- Skills Section
- Certifications Section
- Resume Download Option
- Contact Form
- GitHub & LinkedIn Integration

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript
- HTML5
- CSS3
- Framer Motion
- React Icons
